# AWFN and MDR in Bearing-Fault Diagnosis

## Overview

This repository contains the computational notebook and analysis code associated with a study investigating the relationship between the any-window false-negative rate (AWFN) and the missed detection rate (MDR) in bearing-fault diagnosis.

The analyses examine evaluation results from the Paderborn and MFPT datasets and a matched ablation study. The objective is to investigate how window-level false-negative measurements relate to recording-level missed detections and how this relationship affects model evaluation.
